# LCR - 지역 소멸 위기 극복 플랫폼

## 프로젝트 개요
LCR은 지역 소멸 위기에 대한 인식을 높이고, 정부 정책 정보를 제공하며, 데이터 기반의 분석을 통해 지역 발전을 지원하는 웹 플랫폼입니다.

## 주요 기능

### 1. 개요 (Overview)
- 지역 소멸 관련 정보 제공
- 소멸 위험 지역 현황 분석 (1)

### 2. 지원정책 (Support Policy)
- 정부 지원 정책 정보 (2)
- 지자체별 맞춤형 정책

### 3. 로컬 맵 (Local Map)
- 소멸 위험 지역 지도 시각화
- 지역별 인구 현황 데이터

### 4. 시뮬레이션 (Simulation)
- 인구 변화 예측
- 지역 소멸 지수 계산

### 5. 커뮤니티 (Community)
- 자유 게시판 (3)
- 지역 소멸 관련 Q&A

## 기술 스택
- Frontend: HTML5, CSS3, JavaScript
- Responsive Design: 모바일 최적화
